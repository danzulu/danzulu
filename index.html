AI Workers

Customer Service AI Worker

A platform for shipping reusable business AI agents to production. The Customer Service Worker is a finished, ready-to-use product on WhatsApp: it answers customers, books rooms and appointments, resolves returns and claims, and escalates to a person only when it's truly needed. It is generic by design, so it can be deployed in any business, and it has already been implemented for a hotel.

    Engineering decisions behind it

    • Escalates only when truly needed The agent resolves requests end to end within business policy. Only what falls outside it goes to a person, with the full context attached.
    • Tenant isolation Each business's data, configuration and conversations are isolated, so one worker can safely serve many clients.
    • Private Control Plane A private control plane to configure each deployment and review conversations, kept apart from the customer-facing runtime.
    • WhatsApp-first, direct to Meta Built on the Meta WhatsApp Cloud API with Embedded Signup, behind an internal WhatsAppProvider and a template registry.
    • Safe scope by design Returns & Claims checks evidence against the return policy before approving. Appointments re-check availability right before confirming.
    • Generic core, custom on top Standardized products for speed, plus custom development for specialized needs, from one reusable platform.

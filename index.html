    Engineering decisions behind it

    Escalates only when truly needed

    The agent resolves requests end to end within business policy. Only what falls outside it goes to a person, with the full context attached.

    Tenant isolation

    Each business's data, configuration and conversations are isolated, so one worker can safely serve many clients.

    Private Control Plane

    A private control plane to configure each deployment and review conversations, kept apart from the customer-facing runtime.

    WhatsApp-first, direct to Meta

    Built on the Meta WhatsApp Cloud API with Embedded Signup, behind an internal WhatsAppProvider and a template registry.

    Safe scope by design

    Returns & Claims checks evidence against the return policy before approving. Appointments re-check availability right before confirming.

    Generic core, custom on top

    Standardized products for speed, plus custom development for specialized needs, from one reusable platform.
